# Contributing to prayr

Thanks for helping improve `prayr`. 🙏

## Before opening a pull request

1. Keep changes focused and easy to review.
2. Do not include real prayer requests, private names, credentials, signing keys, private URLs, or machine-specific paths in commits or screenshots.
3. Build the project with:

```bash
./build-local.sh
```

4. Describe what changed and how you tested it.

## Product direction

`prayr` should remain small, calm, local-first, and privacy-conscious. Features should support prayer rather than turn the app into a social network, engagement system, or attention machine.

## Issues

For bugs, include Android version, device model, steps to reproduce, and sanitised logs where useful. Never post private prayer content in an issue.
